# Code of Conduct

## Our Commitment

TensorAeroSpace is a technical community for aerospace simulation, control, and machine learning work. We want collaboration in this project to be direct, useful, and respectful for contributors with different backgrounds, experience levels, and areas of expertise.

By participating in this repository, issues, pull requests, discussions, reviews, or project-related communication spaces, you agree to follow this Code of Conduct.

## Expected Behavior

Contributors are expected to:

- Treat other people with respect, even during technical disagreement.
- Keep feedback focused on the work, evidence, tradeoffs, and maintainability.
- Be clear when stating assumptions, risks, or limitations.
- Accept constructive criticism and revise work when the technical argument supports it.
- Help keep discussions useful for current and future maintainers.
- Respect privacy and avoid sharing private information without explicit permission.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, intimidation, personal attacks, or sustained disruption.
- Insults based on experience level, nationality, language, identity, affiliation, or background.
- Sexualized language or imagery in project spaces.
- Publishing private information such as private email, phone numbers, credentials, tokens, private messages, or private security reports.
- Deliberately derailing technical discussions or repeatedly ignoring maintainer direction.
- Retaliation against people who report conduct or security concerns in good faith.

## Technical Disagreement

Strong technical disagreement is allowed. Keep it grounded in the code, tests, documentation, reproducibility, user impact, and project scope. If a discussion stops making progress, maintainers may pause it, move it to a more suitable venue, or make a decision based on the available evidence.

## Enforcement

Maintainers may take action when this Code of Conduct is violated. Actions may include:

- Asking participants to edit or remove comments.
- Closing or locking issues, pull requests, or discussions.
- Temporarily or permanently limiting participation in project spaces.
- Reporting serious abuse to the relevant platform or organization.

Maintainers should apply this policy consistently and proportionally, with the goal of keeping the project safe and productive.

## Reporting

Report Code of Conduct concerns privately to the maintainers through GitHub or by email at support@tensoraerospace.org. Include links, screenshots, or context when available. Reports will be handled with discretion.

Security vulnerabilities should be reported through the process in [SECURITY.md](SECURITY.md), not through public issues.
