# Настройка Unity среды

## Клонирование репозитория

```shell
git clone git@github.com:tensoraerospace/UnityAirplaneEnvironment.git
```

## Установка зависимостей

Установите пакет для работы с unity ml agents:

```shell
pip install gym==0.20.0 gym-unity==0.28.0
```

## Установка Unity

Установите Unity Hub по ссылке: https://unity.com/download

Скачайте и установите версию Unity 2021.3.5f1 по ссылке: https://unity.com/releases/editor/archive

## Открытие проекта

Откройте проект в Unity Hub. Для этого нажмите на кнопку "Open" и найдите репозиторий на диске. Затем нажмите на кнопку "Open" в папке репозитория.

![Шаг 1](img/1.png){ width=800 }

![Шаг 2](img/2.png){ width=800 }

Затем откройте проект в Unity Hub.

![Шаг 3](img/5.png){ width=800 }

Затем внутри редактора Unity, который откроется вместе с проектом, откройте папку Assets\AlbLab3\Scenes\MLAgentsScenes и выберите нужную сцену, например MLAgentsScene для запуска простой среды.

![Шаг 4](img/6.png){ width=800 }

Среда готова к работе!
