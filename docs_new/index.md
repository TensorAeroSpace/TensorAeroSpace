# Добро пожаловать в документацию TensorAeroSpace! - RL for Aerospace

TensorAeroSpace - это набор объектов управления, сред моделирования OpenAI Gym и реализации алгоритмов Reinforcement Learning (RL)

Github репозиторий: https://github.com/TensorAeroSpace/TensorAeroSpace

## Что такое TensorAeroSpace?

TensorAeroSpace — это open-source фреймворк для глубокого обучения, ориентированный на объекты аэрокосмической отрасли (ракеты, самолёты, БПЛА). Он предоставляет:

- **Модели аэрокосмических объектов**: готовые среды для симуляции полёта
- **Алгоритмы Reinforcement Learning**: современные DRL-алгоритмы для обучения агентов
- **Интеграция с Gym**: стандартные интерфейсы для взаимодействия
- **Обучающие материалы**: пошаговые уроки по анализу и моделированию

## Быстрый старт

1. Установите фреймворк: `pip install tensoraerospace`
2. Выберите модель (например, F16) и агент (например, SAC)
3. Запустите обучение и симуляцию

Подробные инструкции в разделе [User Guide](guide/installation.md).
