Что такое динамическая система
------------------------------
Динамическая система — это объект, состояние которого изменяется во времени под воздействием входов и внутренних законов эволюции. В инженерии систему часто описывают в виде уравнений состояния:

.. math::
   \dot{x}(t) = f\big(x(t), u(t), t\big), \qquad y(t) = g\big(x(t), u(t), t\big)

где :math:`x` — вектор состояния, :math:`u` — вход (управление), :math:`y` — выход (наблюдаемая величина).

Линейные системы и LTI-модель
-----------------------------
Частный (но очень полезный) случай — линейная, инвариантная по времени (LTI) система:

.. math::
   \dot{x}(t) = A x(t) + B u(t), \qquad y(t) = C x(t) + D u(t)

Матрицы :math:`A,B,C,D` задают динамику и измерения. Такая форма удобна для анализа устойчивости, наблюдаемости и управляемости.

Переходный процесс и установившийся режим
----------------------------------------
- Переходный процесс — участок отклика от момента изменения входа до выхода на установившийся режим.
- Установившийся режим — состояние, когда выход перестаёт заметно изменяться (для стационарного входа).

Ключевые метрики качества переходного процесса:
- время нарастания, перерегулирование, время установления, статическая ошибка.

Устойчивость (по Ляпунову — кратко)
-----------------------------------
Система устойчива, если малые возмущения начальных условий приводят к малым отклонениям траектории. Для LTI-систем критерий прост: все собственные значения матрицы :math:`A` должны лежать в левой полуплоскости (неположительная вещественная часть, строго отрицательная — асимптотическая устойчивость).

Управляемость и наблюдаемость
-----------------------------
- Управляемость: можно ли перевести систему из любого начального состояния в любое конечное за конечное время с помощью допустимых управляющих воздействий.
- Наблюдаемость: можно ли восстановить состояние системы по измеряемым выходам за конечный интервал времени.

Для LTI-пары :math:`(A,B)` управляемость проверяется по рангу матрицы Калмана :math:`\mathcal{C} = [B\ AB\ A^2B\ \dots\ A^{n-1}B]`. Аналогично наблюдаемость по :math:`\mathcal{O} = [C^T\ (CA)^T\ \dots\ (CA^{n-1})^T]^T`.

Типовые звенья и частотный взгляд (очень кратко)
-----------------------------------------------
В практике используют аппроксимации типовыми звеньями (апериодическое, интегрирующее, колебательное). Частотные характеристики (Bode, Nyquist) помогают настраивать устойчивость и запасы устойчивости ПИД/МРС-регуляторов.
