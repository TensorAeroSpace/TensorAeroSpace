# Пример: ET-DHP удерживает заданный курс после отказа двигателя (B-747)

Пример обучает агент **Event-Triggered Dual Heuristic Programming (ET-DHP)** удерживать [нелинейный Boeing 747-100](../../../model/b747_nonlinear.md) на исходном курсе $\psi_0 = 0$ после отказа **левого внешнего двигателя** в момент $t = 10$ с. Исходный ноутбук: `example/reinforcement_learning/example_etdhp_b747_engine_failure.ipynb`.

## Что демонстрирует этот пример

* **Помоторный отказ** через пресет [`LEFT_OUTER_ENGINE_FAILURE`](../../../model/b747_nonlinear.md#подсистема-повреждений) — эффективность двигателя №1 обнуляется, и модель двигателя возвращает yaw-момент от асимметричной тяги (по координате двигателя $y_1 = -71{,}7$ ft).
* **Регуляция при постоянном возмущении** — в отличие от синусоидального слежения, после повреждения возникает постоянный yaw-момент, который актор должен компенсировать ненулевым смещением руля. ET-DHP-актор находит это смещение за ~2 эпизода.
* **Сравнение open-loop vs. closed-loop** — без управления $\psi$ уходит до $-85°$ за 50 с; с ET-DHP $\psi$ остаётся в пределах $\pm 0{,}3°$.

## Архитектура

```
вход агента  : x̃ = [ψ_град, r_град/с, φ_град, p_град/с]   (регуляционное состояние)
выход агента : u  = [δ_a_град, δ_r_град]                    (элероны + руль направления, град)
вход среды   : [δ_e_trim, δ_a, δ_r, δ_T_trim]               (4-канальная virtual-команда)
```

Тангаж (руль высоты) и тяга удерживаются на крейсерских триммированных значениях и **никогда** не меняются агентом. Агент борется только с боково-направленным возмущением через элероны и руль направления.

## Почему задача нетривиальна

* Мёртвый двигатель создаёт **постоянный yaw-момент возмущения** ($N_\text{thrust} = -y_1 \cdot T_1 \approx -593\,000$ ft·lb), толкающий нос в сторону отказа.
* B-747 тяжёл ($I_z = 49{,}7 \times 10^6$ slug·ft²); расхождение медленное, но **неограниченное** — open-loop $\psi$ превышает $80°$ за 50 с.
* Установившийся руль направления невелик, но не нулевой (~1{,}8° обратного руля); актор должен научиться постоянному смещению, а не только переходному отклику.

## Гиперпараметры

| Параметр | Значение | Почему |
|---|---:|---|
| `actor_hidden`, `critic_hidden` | (32, 32) | Больше дефолта F-16 — после отказа политика должна выучить ненулевое смещение, а не только малый линейный gain. |
| `Q` | `[100, 1, 5, 0.2]` | $\psi$ — основная цель ⇒ максимальный вес. $\varphi$ важен меньше, но не должен расти. У скоростей малые веса. |
| `R` | `[0.5, 0.5]` | Лёгкий штраф на управление — при отказе двигателя большие смещения руля физически необходимы. |
| `u_bound` | 8° | Актор насыщается на $\pm 8°$. У B-747 рудер $\pm 25°$, но устаноившееся значение ~1{,}8°. |
| `rho` | 0,05 | Lipschitz-константа триггера события — ниже, чем в F-16-примерах, чтобы триггер часто срабатывал в фазе постоянного возмущения. |
| `trigger_floor` | 0,5° | Пол для порога триггера, чтобы $\tilde x \to 0$ не блокировал обновления. |
| `num_epochs_per_trigger` | 10 | Больше итераций внутреннего цикла per trigger ⇒ быстрее обучается установившееся смещение. |

## Конвейер

### 1. Идентификация модели объекта (здоровый самолёт, короткие импульсы)

40 коротких 3-секундных серий мульти-синусного возбуждения по элеронам и рулю направления, со свежим reset среды между каждой серией. Это удерживает состояние ограниченным вблизи точки линеаризации и даёт чистый MSE порядка $10^{-5}$ (per-component, в градусах).

```python
N_BURST, N_BURSTS = 60, 40
for burst in range(N_BURSTS):
    env_id = make_env(damage_profile=None, n_steps=N_BURST + 5)
    obs, _ = env_id.reset()
    for t in range(N_BURST):
        # мульти-синусное PE по da, dr (град)
        da_deg = 1.5 * np.sin(2*np.pi*f_a*t*DT + phase_a) + 0.4 * rng.normal()
        dr_deg = 1.5 * np.sin(2*np.pi*f_r*t*DT + phase_r) + 0.4 * rng.normal()
        ...
```

### 2. Замкнутое обучение в условиях повреждения (8 эпизодов)

Агент обучается на **повреждённом** самолёте с первого эпизода. Здоровое обучение не дало бы возмущения, и триггер не срабатывал бы — для обучения установившегося смещения актору нужен постоянный сигнал ошибки.

```python
agent = ETDHPAgent(n_state=4, n_control=2, state_transform=state_transform, config=cfg)
agent.fit_plant_model(states_arr, actions_arr, next_states_arr,
                      batch_size=128, verbose=False)

for ep in range(8):
    log = run_episode(LEFT_OUTER_ENGINE_FAILURE, learn=True)
    # ...
```

Типичная кривая обучения:

| Эпизод | RMSE ψ (вторая половина) | max \|ψ\| после повреждения | Финальный руль |
|---:|---:|---:|---:|
| 1 | 26,7° | 43,2° | −0,0° |
| 2 | 0,65° | 0,74° | −1,75° |
| 3 | 0,44° | 0,48° | −1,72° |
| ... | ... | ... | ... |
| 8 | 0,26° | 0,28° | −1,80° |

Уже к эпизоду 2 актор обнаруживает компенсацию для отказавшего двигателя.

### 3. Финальная оценка

| Метрика | Значение |
|---|---:|
| MAE ψ (вторая половина) | **0,26°** |
| RMSE ψ (вторая половина) | 0,26° |
| Пиковый \|ψ\| после повреждения | 0,28° |
| Установившийся руль | −1,80° (правый руль по соглашению CR-2144) |
| Установившийся элерон | −0,22° |

## Open-loop vs. ET-DHP

Тот же сценарий с **отключённым** агентом (нулевые элероны/руль, только трим-руль высоты + трим-тяга):

| Время | Open-loop ψ | ET-DHP ψ |
|---:|---:|---:|
| t = 10 с (повреждение) | 0° | 0° |
| t = 30 с | −20° | −0,3° |
| t = 60 с | **−85,5°** | **−0,28°** |

Без агента самолёт неуправляемо разворачивается в сторону мёртвого двигателя; с ET-DHP отклонение по курсу остаётся менее $0{,}3°$ всю фазу после повреждения.

## Что выучил агент

Установившийся выход актора (~ −1,8° руль, малый элерон) тесно совпадает с аналитической оценкой $\Delta N_\text{thrust} / (q_\text{dyn}\, S\, b\, C_{n_{\delta_r}}) \approx 1{,}6°$ на крейсе FL200. Агент пере-открыл каноническую компенсацию отказа двигателя минимизацией квадратичной стоимости — без явного шага синтеза регулятора.

**Знак установившегося руля.** Производные CR-2144 используют $C_{n_{\delta_r}} < 0$ — положительный руль даёт *отрицательный* yaw-момент. После отказа двигателя №1 ($N_\text{thrust} < 0$, нос влево), руль должен добавить положительный аэродинамический $N$ для компенсации тяги-момента, то есть $\delta_r < 0$. Отрицательный установившийся руль агента согласован с этим выводом.

## Замечания и расширения

* **Тангаж и высота.** Удержание тяги на трим-значении 4-двигательной конфигурации с одним мёртвым двигателем даёт ~25% дефицит тяги; самолёт медленно снижается. На практике FTC-стек закрыл бы и каналы тангажа/тяги — например, скомбинировав этот боковой регулятор с [IHDP-трекером тангажа](../ihdp/example_ihdp_nonlinear_b747.md) и простым PI по скорости.
* **Другие сценарии отказа.** Замените `LEFT_OUTER_ENGINE_FAILURE` на `LEFT_TWO_ENGINES_OUT` для случая максимальной асимметрии (~50% тяги). Установившийся руль примерно удвоится; возможно, понадобится `u_bound = 12°` и снижение `Q[2]`, чтобы самолёт лёг с небольшим естественным креном в сторону мёртвых двигателей.
* **Ablation без руля.** Убрав канал руля направления, контроль yaw возможен только через дигедральный эффект крена, что требует нескольких секунд раскачки крена. Полезно как stress-тест.
